## モデル概要

MoziAI-27B-3.8は、中国の金融インフルエンサー陳雨墨氏チームが開発したローカルオープンソースマルチモーダルAI大規模モデル（金融分野強化、ビジョン対応、ツール呼び出し対応、コンシューマGPUでのローカルデプロイ対応）です。moziAI-27B-3.8はオープンソースベースモデルQwen3.8-27B（Dense 27Bアーキテクチャ、MITライセンス）を基盤とし、陳雨墨チーム独自開発の（金融データ＋金融ドメイン能力＋トレーニング方法＋動的七次元思考フレームワーク＋エージェントLOOP反思迭代メカニズム＋ハイブリッド量子化アルゴリズムMoziSmartBit）を組み合わせて開発されました。個人と企業のローカルデプロイのハードルを下げ、無料商用利用を許諾しています。ローカルのコンシューマGPUでデプロイ可能であるため、クラウドトークンコストを大幅に節約し、7×24時間のトークン自由を実現するとともに、ローカルデータのプライバシーとセキュリティを確保します。

**動的七次元思考フレームワーク＋エージェントLOOP迭代メカニズム**：MoziAI独自開発のコア推論モードです。タスクの複雑度を知的に判断し、簡単なタスクでは二次元思考で素早く回答し、中程度の複雑なタスクでは五次元思考を起動し、高度に複雑なタスクでは完全な七次元思考＋LOOP反思迭代メカニズムを起動します。自分より何十倍も大きな trillion パラメータモデルの複雑なタスク解決能力に挑戦しつつ、簡単なタスクの軽快な応答を損ないません。ローカルモデルでも、熟練のヒューマンエキスパートの「先に考えてから行動する」能力を養うことを可能にし、同等サイズのモデルと比較してこの独自のコア推論フレームワークは非常に特徴的です。

**独自開発のMoziSmartBit知的量子化技術により**、270億パラメータの Dense モデルは約12.79 GBに圧縮され、通常のQ4_K_M量子化モデル（約17 GB）より3.3 GB（約20%）小さくなっています。精度とサイズの最適バランスを実現し、FP16の約99%の精度品質を提供します。

本モデルはAI大規模モデルの汎用能力を保持しつつ、以下を強化しています：金融垂直ドメインアプリケーション、金融Q&A、量的プログラミング、ツール呼び出し、汎用プログラミング、さまざまなエージェントプラットフォームとの互換性。

モデル開発者である陳雨墨は、本モデルをローカル金融データ分析、量的戦略開発、市場調査、あらゆる種類の記事執筆、プロジェクト全体の開発推進、汎用プログラミング、OpenClaw/Hermesによる256K長コンテキストの複雑なタスク実行に頻繁に使用しています。

llama.cpp、Ollama、LM Studioなどのメインストリーム推論フレームワークによる無料ローカルデプロイをサポートしています。

**リリース日：2026-08-30** | **バージョン：V3.8**

## モデルの特長

- **🧠 動的七次元思考フレームワーク**：MoziAI独自開発のコア推論フレームワークです。あらゆるタスクに直面した際、モデルは最初に**moziAI-Think**タグを出力し、タスクの複雑度に応じて構造化思考を動的に展開します——簡単な質問の「タスク理解＋リソース要件」の二次元速答（Level 0）から、分析診断の五次元評価（Level 1）、複雑な開発・戦略設計の全七次元深層推論（Level 2）まで：①タスク理解 ②複雑度評価 ③依存関係 ④リスク評価 ⑤リソース要件 ⑥検収基準 ⑦実行戦略。
- **🧠 エージェントLOOP迭代メカニズム**：複雑なタスクに対し、MoziAIは自動的に**moziAI-Loop**の迭代モードに入ります：第1ラウンド実行＋評価 → 第2ラウンド調整＋検証。出力が自己検証された後に最終的な回答を提供し、一度に生成するのではありません。これは、モデルが単に「質問に答える」のではなく、熟練エンジニアのように問題を分解→解決策を評価→実行→振り返り→最適化を行うことを意味し、複雑なタスクの精度と実行可能性を大幅に向上させます。簡単な質問とタスクではLoop迭代メカニズムを自動的に無効にします。
- **🧠 MoziSmartBit知的量子化**：MoziAI独自開発の階層型知的量子化。精度とサイズの最適バランスを実現し、約12.79 GBに圧縮、FP16約99%の精度を維持。
- **🧠 金融垂直ドメイン集中**：金融Q&A、量的プログラミング、ツール呼び出しの深層最適化。金融分野はモデルの幻覚に対する許容度が極めて低く、汎用モデルと比較したMoziAIの垂直ドメイン能力の深層強化が実証されています。
- **多言語サポート**：201の言語と方言をサポート。中国語能力が特に最適化されており、英語、日本語、韓国語、ドイツ語、フランス語、スペイン語、ポルトガル語などの主要言語もカバーしています。
- **汎用プログラミング能力**：フルスタック開発、コードデバッグ、アーキテクチャ設計、スクリプト作成をサポート。Python/JS/TS/Go/Rustなどの主要言語を網羅。
- **記事執筆能力**：レポート、分析記事、技術ドキュメント、クリエイティブコンテンツなど、多ジャンルの高品質執筆をサポート。
- **ビジョン理解**：マルチモーダルビジョンをサポート。スクリーンショットをチャットウィンドウに貼り付けると、モデルが画像内の情報を理解できます。
- **マルチフレームワークサポート**：llama.cpp、Ollama、LM Studio、Janなどのメインストリーム推論フレームワークに対応。
- **マルチエージェントプラットフォームサポート**：OpenClaw、Hermes、OpenCode、Cursor、Windsurf、Claude Code、Codexなどの国内外の主要AI IDEとエージェントフレームワークに深い互換性。ツール呼び出しとマルチターンタスクオーケストレーションをネイティブにサポートし、すぐに使用できます。

## MoziSmartBit知的量子化技術

従来の量子化方式はすべての層に統一精度を適用しますが、陳雨墨チーム独自開発の**MoziSmartBit知的量子化**は、Denseモデルの構造特性に合わせたインテリジェント差別化量子化戦略を採用し、サイズと精度の最適バランスを達成。モデル品質はQ4_K_Mフォーマットを上回り、サイズはわずか12.79 GB、圧縮比4.0x、精度保持率は約99%です。

### 圧縮効果

- **量子化精度損失が極めて小さい**：トレーニングによる向上 > 量子化による損失。トレーニング後のMoziAI-27Bは金融分野テキストのPPLがトレーニング前のbf16ベースモデルを上回り、同種のAIモデルと比較して幻覚と混乱を軽減。
- **モデルサイズを4.0倍に圧縮**：FP16（~54 GB）から~12.79 GBに圧縮。Q4_K_Mの~17 GBよりも大幅に小さく、VRAMとストレージのハードルを大幅に低減。
- **コンシューマGPUでデプロイ可能**：ハイエンドGPUが必要だった27B Dense大規模モデルが、16 GB VRAMでローカルデプロイ可能に。20 GB以上のGPUでは完全な256K長コンテキスト推論を実現。

### 比較優位

**vs Q4_K_M（~17 GB）**：約20%小型（~12.79 GB）、Q4_K_Mより高い精度、VRAMハードルが更低く16 GB GPUでデプロイ可能、20 GB以上のGPUで256K長コンテキストをスムーズに実行。

**vs オリジナルFP16（~54 GB）**：約4.0倍の圧縮比、約99%の精度保持。プロフェッショナル級GPUからコンシューマGPUまで、ローカル256K長コンテキスト推論が可能に。

## MTP推測デコード（重要な加速特性）

本モデルにはMTP（Multi-Token Prediction）推測デコード層が組み込まれています。有効にすると推論速度が**1.5-2倍**に向上します。これはQwen3.8アーキテクチャのネイティブ特性であり、MoziAIは完全なMTP重みを保持しています。

### MTPの原理

MTPはモデルアーキテクチャに軽量な予測ヘッド（Draft Model）を追加訓練し、メインモデルの検証前に後続トークンを事前に推測します。これにより、メインモデルのforward回数を削減し、推論レイテンシを大幅に低減します。

### llama.cppでのMTP有効化パラメータ

```bash
--spec-type draft-mtp \
--spec-draft-n-max 2 \
--spec-draft-p-min 0.75
```

| パラメータ | 推奨値 | 説明 |
| --- | --- | --- |
| --spec-type | draft-mtp | MTP推測デコードを有効化 |
| --spec-draft-n-max | 2 | 1回あたり最大推測トークン数（推奨値、受容率約80%） |
| --spec-draft-p-min | 0.75 | 最低受容確率閾値（0.0-1.0、大きいほど保守的） |

### MTPパラメータ調整ガイド

| spec-draft-n-max | 受容率 | 適用シナリオ |
| --- | --- | --- |
| 1 | ~90% | 最も保守的、速度向上は最小だが最も安全 |
| **2** | **~80%** | **推奨：速度と正確性のバランス** |
| 3 | ~71% | 汎用シナリオ、速度向上が顕著 |
| 4-5 | ~60-65% | クリエイティブライティング、コード生成 |
| 6 | ~50-55% | 純テキスト長出力（p-min調整が必要） |

> ⚠️ **注意**：MTP推測デコードは出力品質に悪影響を与えません（誤推測はメインモデルによって修正されます）。推論速度のみに影響します。`spec-draft-n-max`は2から開始し、実際の受容率に基づいて調整することを推奨します。

## llama.cpp起動コマンド

```bash
llama-server \
  -m V3.8/moziAI-27B-3.8-Q4_K_M-Qwen3.8-27B.gguf \
  --mmproj V3.8/moziAI-27B-3.8-mmproj-F16.gguf \
  --chat-template-file V3.8/chat-template-moziai-27B-v38.jinja \
  -c 131072 -ngl 99 -t 28 \
  --batch-size 1024 --ubatch-size 128 \
  --flash-attn auto \
  --cache-type-k q4_0 --cache-type-v q4_0 --kv-unified \
  --poll 0 \
  --reasoning auto --reasoning-budget 1024 --reasoning-format deepseek-legacy \
  --spec-type draft-mtp --spec-draft-n-max 2 --spec-draft-p-min 0.75 \
  --host 0.0.0.0 --port 8080 \
  --temp 0.6 --top-p 0.95 --top-k 20
```

> 💡 **MTPを無効にする場合**：MTP推測デコードを無効にするには、起動コマンドから`--spec-type draft-mtp`、`--spec-draft-n-max 2`、`--spec-draft-p-min 0.75`の3行を削除してください。無効にすると推論速度は約30-50%低下しますが、VRAM使用量が減少します。

## Ollamaデプロイ

```bash
# Modelfileを作成
FROM ./moziAI-27B-3.8-Q4_K_M-Qwen3.8-27B.gguf

PARAMETER top_p 0.95
PARAMETER top_k 20
```

## ベンチマーク評価

> 💡 **ダウンロードのヒント**：上記リンクをクリックしてHuggingFaceリポジトリに入り、「Files and versions」タグでV3.8ディレクトリ内のすべてのファイル（メインモデル、ビジョン投影、チャットテンプレート）をダウンロードしてください。3つのファイルを同じディレクトリに配置してください。

⚠️ **重要：ビジョン機能には追加のmmprojファイルの読み込みが必要です**

本モデルはマルチモーダルビジョンをサポートしています。ビジョン投影ファイル（mmproj）はバージョンディレクトリに含まれています。

- **ビジョンファイル**：`moziAI-27B-3.8-mmproj-F16.gguf`（約927 MB、BF16精度）
- **配置場所**：GGUFモデルファイルと同じバージョンディレクトリに配置
- **読み込み方法**：llama-server起動時に`--mmproj`パラメータで読み込み

> ビジョンファイルを読み込まない場合、画像理解能力が失われ、純粋なテキスト会話能力のみが保持されます。

## クイックスタート

### 1. モデルファイルをダウンロード

HuggingFace / ModelScopeからV3.8ディレクトリ内のすべてのファイルをローカルにダウンロード：

```
V3.8/
├── moziAI-27B-3.8-Q4_K_M-Qwen3.8-27B.gguf      # メインモデル（必須）
├── moziAI-27B-3.8-mmproj-F16.gguf              # ビジョン投影（オプション）
└── chat-template-moziai-27B-v38.jinja           # チャットテンプレート（推奨）
```

### 2. 推論サービスを起動

完全な推奨構成の起動コマンドは、上記の[llama.cpp起動コマンド](#llamacpp起動コマンド)セクションを参照してください。

最小限の起動（コアパラメータのみ）：

```bash
llama-server \
  -m V3.8/moziAI-27B-3.8-Q4_K_M-Qwen3.8-27B.gguf \
  --chat-template-file V3.8/chat-template-moziai-27B-v38.jinja \
  -c 131072 -ngl 99
```

> ビジョン機能が必要な場合は`--mmproj V3.8/moziAI-27B-3.8-mmproj-F16.gguf`を追加してください。

### 3. 使い始める

ブラウザで`http://localhost:8080`を開くとチャットを開始できます。
